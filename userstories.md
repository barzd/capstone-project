**USER STORIES__**

- User Accounts : As a student, I want to be able to create an account, so that I can submit and manage lost items reports
  
- Item Reporting : As a student, I want to report a lost item, so that others can help me find it
  
- AI Matching & Search : As a student, I want the system to suggest possible matching found items, so that I can recover my
  items faster

- Claims & Verification : As campus staff, I want to verify a user's ownership claim, so that items are returned to the
  correct person

- Pickup & Recovery : As a verified owner, I want to schedule a pickup, so that I know when and where to retrieve my item

- **Photo Uploads:** As a student, I want to upload a photo of my lost item, so that others can identify it more easily.

- **Item Descriptions:** As a staff member, I want the system to suggest item descriptions and categories, so that I can add found items faster.

- **Search Filters:** As a student, I want to filter items by category, color, location, and date, so that I can find possible matches more easily.

- **Match Notifications:** As a student, I want to receive a notification when a possible match is found, so that I can check if my item has been turned in.

- **Claim Submission:** As a student, I want to submit a claim for an item I believe belongs to me, so that staff can verify my ownership.

- **Claim Status:** As a student, I want to check the status of my claim, so that I know whether it has been approved or rejected.

- **Report Management:** As a student, I want to edit or close my lost item report, so that I can keep my information updated if I find my item.

- **Pickup Directions:** As a verified owner, I want to see directions to the pickup location, so that I know where to collect my item.

- **Privacy Protection:** As a student, I want my personal information to stay private, so that my contact details are not shown to everyone using the system.

- **Staff Dashboard:** As a staff member, I want to view and manage lost item reports and claims, so that I can keep the lost and found system organized.

- **Item Recovery Confirmation:** As a student, I want to mark my item as recovered, so that others know it is no longer missing.

- **Password Recovery:** As a user, I want to reset my password if I forget it, so that I can regain access to my account.
